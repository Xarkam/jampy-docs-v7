===============================
How to create registration form
===============================



Download example from here:

   :download:`auth.zip <../../_static/auth.zip>`


In this topic we'll assume that you have created a :doc:`users </how_to/authentication/how_to_authenticate_from_custom_users_table>` item from the 
previous topic.

Now we create a *register.html* file.

The task server module has the following ``on_request`` event handler:

.. code-block:: py

  def on_request(task, request):
        parts = request.split('/')
        if not parts[0]:
            ...
        elif parts[0] == 'register.html':
            if request.method == 'POST':
                form = request.form.to_dict()
                if form['password'] != form['password2']:
                    return task.serve_page('register.html', 
                        register_format("Passwords don't match", form))
                else:
                    users = task.users.copy(handlers=False)
                    users.set_where(login=form['login'])
                    users.open()
                    if users.rec_count:
                        return task.serve_page('register.html', 
                            register_format("Existing login, please use different login!!!", form))
                    users.append()
                    users.name.value = form['name']
                    users.login.value = form['login']
                    users.password_hash.value = task.generate_password_hash(form['password'])
                    users.role.value = 2
                    users.post()
                    users.apply()
                    return task.redirect('/login.html')
            else:
                return task.serve_page('register.html', register_format())

It checks if there is 'register' in url and then looks if there is no user 
with the login and then register the user.
