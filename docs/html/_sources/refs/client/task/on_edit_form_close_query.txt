========================
on_edit_form_close_query
========================

.. js:function:: on_edit_form_created(item)

**domain**: client 

**language**: javascript

**class** :doc:`Task class </refs/client/task_api>`

Description
===========

The ``on_edit_form_close_query`` event is triggered by the 
:doc:`close_edit_form </refs/client/item/m_close_edit_form>`
method of the item.

The ``item`` parameter is the item that triggered the event.

Example:

.. code:: js

      function on_edit_form_close_query(item) {
          return true;
      }
