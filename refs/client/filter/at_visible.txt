=======
visible
=======

.. js:attribute:: Filter.visible

    :domain: client
    :language: javascript
    :class: :js:class:`Filter`


Description
===========


If the value of this property is **true** the input control for this filter will
be created by the
:doc:`create_filter_inputs </refs/client/item/m_create_filter_inputs>`
method, if the **filters** option in not specified.
