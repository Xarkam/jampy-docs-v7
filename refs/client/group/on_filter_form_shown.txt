====================
on_filter_form_shown
====================

.. js:function:: Group.on_filter_form_shown(item)

    :domain: client
    :language: javascript
    :class: :js:class:`Group`

Description
===========

The ``on_filter_form_shown`` event is triggered by the
:js:meth:`create_filter_form <Item.create_filter_form>`
method of the item when the form has been shown.

This event, if defined, is triggered for every item of the group, whose
:js:meth:`create_filter_form <Item.create_filter_form>`
method has been called.

Parameter
=========

.. list-table::
   :header-rows: 1
   :widths: 5 5 30

   * - Parameter
     - Type
     - Description
   * - ``item``
     -
     - The item that triggered the event.
