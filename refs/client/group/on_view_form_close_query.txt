========================
on_view_form_close_query
========================

.. js:function:: Group.on_view_form_close_query(item)

    :domain: client
    :language: javascript
    :class: :js:class:`Group`

Description
===========

The ``on_view_form_close_query`` event is triggered by the
:js:meth:`close_view_form <Item.close_view_form>`
method of the item.

Parameter
=========

.. list-table::
   :header-rows: 1
   :widths: 5 5 30

   * - Parameter
     - Type
     - Description
   * - ``item``
     -
     - The item that triggered the event.
