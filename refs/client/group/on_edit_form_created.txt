====================
on_edit_form_created
====================

.. js:function:: Group.on_edit_form_created(item)

    :domain: client
    :language: javascript
    :class: :js:class:`Group`

Description
===========

The ``on_edit_form_created`` event is triggered by the
:js:func:`on_create_edit_form <Item.create_edit_form>`
method of the item when the form has been created but not shown yet.

This event, if defined, is triggered for every item of the group, whose
:js:func:`on_create_edit_form <Item.create_edit_form>`
method has been called.

Parameter
=========

.. list-table::
   :header-rows: 1
   :widths: 5 5 30

   * - Parameter
     - Type
     - Description
   * - ``item``
     -
     - The item that triggered the event.
