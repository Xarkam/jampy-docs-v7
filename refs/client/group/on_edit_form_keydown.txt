====================
on_edit_form_keydown
====================

.. js:function:: Group.on_edit_form_keydown(item, event)

    :domain: client
    :language: javascript
    :class: :js:class:`Group`

Description
===========

The ``on_edit_form_keydown`` event is triggered when the keydown event
occurs for the
:js:attr:`edit_form <Item.edit_form>`
of the item.

Parameters
==========

:guilabel:`item` is the item that triggered the event.

:guilabel:`event` is JQuery event object.
