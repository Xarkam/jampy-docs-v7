==================
on_edit_form_shown
==================

.. js:function:: Group.on_edit_form_shown(item)

    :domain: client
    :language: javascript
    :class: :js:class:`Group`

Description
===========

The ``on_edit_form_shown`` event is triggered by the
:js:meth:`create_edit_form <Item.create_edit_form>`
method of the item when the form has been shown.

This event, if defined, is triggered for every item of the group, whose
:js:meth:`create_edit_form <Item.create_edit_form>`
method has been called.

Parameter
=========

:guilabel:`item` is the item that triggered the event.
