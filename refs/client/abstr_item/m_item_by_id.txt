==========
item_by_ID
==========

.. js:function:: AbstractItem.item_by_ID(ID)

    :domain: client
    :language: javascript
    :class: :js:class:`AbstractItem`

Description
===========

item_by_ID searches among all items of the project :doc:`task tree </programming/task_tree>`,
starting with the current item, for an item whose :js:attr:`ID <AbstractItem.id>` attribute is
equal to the ID parameter.
