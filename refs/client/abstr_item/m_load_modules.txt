============
load_modules
============

.. js:function:: AbstractItem.load_modules(module_array, callback)

    :domain: client
    :language: javascript
    :class: :js:class:`AbstractItem`

Description
===========

Use **load_modules** method to dynamically load specified modules before
executing the **callback**.

The method works the same way as
:js:meth:`load_module <AbstractItem.load_module>`,
only loads and initializes all modules of items specified in the
**module_array**.

Parameters
==========

.. list-table::
   :header-rows: 1
   :widths: 20 15 65

   * - Parameter
     - Type
     - Description
   * - ``module_array``
     - ``array``
     - The list of modules to load and initialize.
   * - ``callback``
     - ``function``
     -

Example
=======

Bellow, the do_some_work function is executed only when modules of the item and
its owner has been loaded:

.. code-block:: js

    function some_work(item) {
        item.load_modules([item, item.owner], do_some_work);
    }

    function do_some_work(item) {
        // some code
    }
