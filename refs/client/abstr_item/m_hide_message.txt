============
hide_message
============

.. js:function:: AbstractItem.hide_message(form)

    :domain: client
    :language: javascript
    :class: :js:class:`AbstractItem`

Description
===========

Use :js:meth:`hide_message <AbstractItem.hide_message>` method to close a modal form created by
:js:meth:`message <AbstractItem.message>` method

Parameter
=========

:guilabel:`form` is a JQuery object returned by :js:meth:`message <AbstractItem.message>` method.
