============
hide_message
============

.. js:function:: AbstractItem.hide_message(form)

    :domain: client
    :language: javascript
    :class: :js:class:`AbstractItem`

Description
===========

Use **hide_message** method to close a modal form created by
:js:func:`message <AbstractItem.message>` method

The **form** parameter is a JQuery object returned by
:js:func:`message <AbstractItem.message>` method.
