=========
each_item
=========

.. js:function:: AbstractItem.each_item(function(item))

    :domain: client
    :language: javascript
    :class: :js:class:`AbstractItem`

Description
===========

Use each_item method to iterate over :js:attr:`items <AbstractItem.items>` owned by this object.

The :guilabel:`each_item()` method specifies a function to run for each child item (child item
is passed as a parameter).

You can break the each_item loop at a particular iteration by making the callback
function return false.

Example
=======

The following code will output all catalogs of the project in a browser console:

.. code-block:: js

    function on_page_loaded(task) {
        task.catalogs.each_item(function(item) {
            console.log(item.item_name);
        })
    }
