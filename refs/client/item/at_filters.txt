=======
filters
=======

.. js:attribute:: Item.filters

    :domain: client
    :language: javascript
    :class: :js:class:`Item`

Description
===========

Lists all
:js:class:`Filter_api`
objects of the item.

Example
=======

.. code-block:: js

    function invoices_filters(invoices) {
        for (var i = 0; i < invoices.filters.length; i++) {
            console.log(invoices.filters[i].filter_caption, invoices.filters[i].value);
        }
    }
