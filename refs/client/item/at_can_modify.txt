==========
can_modify
==========

.. js:attribute:: Item.can_modify

    :domain: client
    :language: javascript
    :class: :js:class:`Item`

Description
===========

Set the ``can_modify`` property to false if you need to prohibit changing
of the item in the visual controls.

When ``can_modify`` is true the
:js:meth:`can_create <Item.create>`,
:js:meth:`can_edit <Item.can_edit>`,
:js:meth:`can_delete <Item.can_delete>`
methods return false.

By default the ``can_modify`` property is true.
