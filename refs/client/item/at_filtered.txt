========
Filtered
========

.. js:attribute:: Item.filtered

    :domain: client
    :language: javascript
    :class: :js:class:`Item`

Description
===========

Specifies whether or not filtering is active for a dataset.

| Check ``filtered`` to determine whether or not local dataset filtering is in effect.
| If ``filtered`` is ``true``, then filtering is active.
| To apply filter conditions specified in the :js:meth:`on_filter_record <Item.filter_record>`
| event handler, set ``filtered`` to ``true``.
