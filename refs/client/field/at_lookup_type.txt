===========
lookup_type
===========

.. js:attribute:: Field.lookup_type

**domain**: client

**language**: javascript

**class** :js:class:`Field`


Description
===========

For
:doc:`lookup fields </programming/data/lookup_fields>`
identifies the type of the
:js:attr:`lookup_value <Field.lookup_value>`,
otherwise returns the value of
:js:attr:`field_type <Field.field_type>`
attribute.
