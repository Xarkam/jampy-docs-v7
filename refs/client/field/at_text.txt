====
text
====

.. js:attribute:: Field.text

**domain**: client

**language**: javascript

**class**: :js:class:`Field`


Description
===========

Use **text** property to get or set the text value of the field.

Getting text property value
---------------------------

Gets the value of the
:js:attr:`value <Field.value>`
property and converts it to text.

Setting text property value
---------------------------

Converts the text to the type of the field and assigns its :js:attr:`value <Field.value>`
property to this value
